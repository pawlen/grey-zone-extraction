# 灰区行动 · GREY ZONE EXTRACTION

一款运行在浏览器中的 **3D 第一人称搜打撤（Extraction Shooter）单机硬核游戏**，使用 Three.js + 原生 JavaScript 实现，无外部商业美术资源，模型/贴图由 Blender 脚本或运行时程序化生成。已扩展为 **6 张大型地图**，拥有起伏地形、程序化天空、3D 草地与树木、分级资源点，以及骨骼蒙皮敌人与程序化 PBR 材质。现已内置 **Blender 资产管线**：角色由 Blender 程序化建模并导出骨骼蒙皮 GLB，同时保留 PBR 材质与骨骼动画资产接口。

**在线试玩：** https://pawlen.github.io/grey-zone-extraction/

> **搜刮 · 交战 · 撤离。** 死亡会带走你身上的一切，只有活着抵达撤离点，战利品才真正属于你。

## 快速开始

### 方式一：双击启动（Windows）

双击 **`start.bat`**，脚本会启动本地服务器并自动打开浏览器（优先使用 Node，其次 Python）。

### 方式二：命令行

```bash
# Node.js（推荐，仓库内已带静态服务器）
node server.js
# 或者 npm start

# 或 Python
python -m http.server 8080
```

然后访问 **http://localhost:8080**。

> 由于浏览器对 ES Module 的 CORS 限制，请通过 HTTP 服务器访问，不要直接双击 `index.html`。
> Three.js 已内置在 `vendor/` 目录中，**无需联网**即可运行。

**环境要求：** 支持 WebGL 2 的现代浏览器（Chrome / Edge / Firefox 最新版）。推荐使用鼠标 + 键盘，进入战局后点击画面锁定鼠标。

## 核心玩法

### 战局循环

1. 在基地选择地图、配置武器与装备，点击 **开始行动**。
   基地仓库同屏展示仓库、装备槽、背包、弹挂与保险箱，可直接拖拽整理与装备。
2. 进入灰区后搜索木箱、储物柜、保险柜等容器，击杀拾荒者与掠夺者。
3. 在倒计时结束前抵达地图任一 **撤离点**（罗盘上有绿色标记），在区域内停留 8 秒即可撤离。
4. **撤离成功**：背包中的战利品自动入库，装备、弹挂与保险箱保留。
   **阵亡 / 超时 / 主动放弃**：装备、弹挂与背包全部遗失，**只有保险箱内的物品会被带回**。

### 硬核系统

- **部位伤害**：头部、胸部、腹部、双臂、双腿独立计算生命值。头部或胸部归零立即死亡；四肢残废会降低移动速度、射击精度和换弹速度。
- **护甲与穿透**：护甲分 1–5 级，弹药有穿透值。低穿透弹会被高等级护甲大幅减伤，但护甲耐久会随受击下降，耐久归零即失效。共有 7 件护甲与 5 款头盔，重量与防护各异。
- **弹挂系统**：装备弹挂后额外获得独立携带空间（3×2 / 4×3 / 5×3）。换弹、医疗包与绷带会自动从弹挂、背包和保险箱中取用；阵亡时弹挂与其内容一并遗失。
- **一体化基地仓库**：行动准备就是仓库界面（参考暗区突围 / 三角洲行动）。同屏显示网格仓库、角色展示台、装备槽、背包 / 弹挂 / 保险箱，可在它们之间自由拖拽、双击快速转移；点击任意物品会在下方显示属性与操作（装备、放入容器、出售）。原列表仓库与「整理物品」弹层已合并移除。
- **可旋转角色展示台**：仓库中央是一个带金色展台与浮尘效果的 3D 干员（参考暗区突围大厅）。默认接入商用级 Mixamo Vanguard 角色（自带完整护甲/头盔/背包，武器按装备实时挂载）；程序化 `operator.glb` 仍保留为回退。按住拖拽可自由旋转并保留惯性，正面 / 左侧 / 背面 / 右侧角度按钮与左右逐档按钮可快速转向，双击复位正面，带等级 / 军衔铭牌。
- **局内换装**：战局中按 `Tab` 打开背包，在右侧装备槽区域可直接把搜刮到的武器、护甲、头盔、弹挂或背包拖上去替换；双击装备类物品也能快速穿戴。换下来的装备会回到原容器或背包，当前武器替换后立即生效。
- **流血**：受击有概率进入流血状态，持续扣血，需要使用绷带止血；医疗包恢复部位生命值，但无法修复残废部位。
- **弹药管理**：弹匣、备用弹药分离。换弹会从弹挂 / 背包 / 保险箱中自动取用对应口径的弹药，优先使用高穿透弹种。共有 15 种弹药，分为标准、穿甲、空尖等类型。
- **负重**：超过 22kg 后移动速度下降；高价值物品往往轻巧，适合塞进保险箱。
- **体力**：冲刺消耗体力，负重越高、腹部受伤时消耗越快。
- **Blender 武器模型**：15 把武器由 Blender 脚本参数化生成并导出 GLB，包含导轨、机械瞄具、红点/瞄准镜、弹匣、枪托与戴手套的双手；带 `muzzle` 枪口节点与 Idle/Aim/Fire/Reload 动作，接入第一人称武器状态机。
- **世界地形**：所有地图都是程序化起伏地形，带坡度与高度差；陡坡会阻挡移动，建筑与出生点/撤离点会平整地基。地图边界由上升的山体、岩壁、树林或围墙构成，不再是一堵突兀的空气墙。
- **天空与植被**：半球天空穹顶带渐变、云层、太阳光晕与主题化雾效；地面采用多层顶点色（草/泥土/岩石/雪）与程序化细节贴图。植被为真实几何体：随风摆动的 3D 草丛（实例化）、带枝干与叶簇卡片的阔叶/针叶树、灌木与岩石，而不是贴图面片。
- **分级资源点**：地图被划分为高价值 / 中价值 / 低价值资源区，高价值区有额外的稀有战利品并配有守卫；资源区之外只有极少数野外物资。资源点带名称、信标与进入提示，围绕建筑和营地布置。
- **Blender 角色资产**：敌人、干员、武器、18 件装备与 8 种搜刮容器均由 `tools/blender/` 下的 bpy 脚本程序化建模并导出 GLB（贴图 WEBP 压缩，总计约 23MB），通过 `assets/manifest.json` 自动加载；未配置 GLB 时自动回退到内置的程序化模型。
- **动作系统（AnimationMixer）**：Blender 角色内置 Idle/Walk/Run/Aim/Fire/Death 六段骨骼动画，支持交叉淡入与单次播放；武器挂在右手骨骼上，行走随臂摆动、瞄准抵肩，中弹后侧向倒地。资源点守卫原地警戒，只有巡逻队会沿路线巡逻。
- **真实弹道与掩体**：敌人射击改用真实射线检测，围栏、集装箱、墙体与起伏地形都会挡住子弹；农田围栏已加高并实体化，不再出现子弹穿栏。
- **边界与穿模修复**：地图物理边界内侧增加连续的可见岩壁/混凝土围墙与碰撞，玩家不会撞到凭空出现的空气墙；植被不再生长进建筑，树木/容器会与建筑保持安全距离，枪械贴近墙面时会自动收起。
- **画面升级**：UnrealBloom 泛光 + SSAO 环境光遮蔽 + SMAA + 电影感调色（对比度/饱和度/暗角/颗粒/色散/锐化）；阳光阴影改为跟随玩家的 2048 贴图（40m 覆盖）；角色使用 1024 迷彩/皮肤与程序化法线；GLB 贴图使用 WEBP 压缩。
- **世界 PBR 材质**：六张地图的墙体、地面与岩壁改用 Poly Haven CC0 1K 贴图（albedo/normal/roughness），通过 `assets/manifest.json` 的 18 组主题材质自动替换。
- **更新公告**：主菜单新增公告板，完整记录从初代 v1.0 到 v1.13 的全部版本更新内容。
- **材质 / 动画管线**：启动时通过 `assets/manifest.json` 加载外部 GLB 敌人/武器与 PBR 贴图组；骨骼动画支持 idle/walk/run/aim/fire/reload/death 状态与交叉淡入。未配置外部模型时，使用内置的骨骼蒙皮人形与程序化 PBR 材质，同样由 AnimationMixer 驱动。详见 [assets/README.md](assets/README.md)。
- **PBR 环境光照**：用程序化天空生成 PMREM 环境贴图，金属武器、护甲与岩石拥有真实高光；墙体和地面可使用外部 albedo/normal/roughness/metalness/AO 贴图组，并按 `factory_wall`、`forest_ground` 等主题命名自动替换。
- **敌人 AI**：巡逻 → 听觉调查 → 视野发现 → 交火 → 搜索最后目击点。枪声会吸引附近敌人，敌人会利用掩体接近你。命中头部收益极高。
- **战利品经济**：物品有稀有度、重量、估值。仓库中的物品可以在商人处出售（55% 估价），也可以购买武器、弹药、护甲、弹挂、医疗品与背包。
- **本地存档**：资金、仓库、装备（含弹挂）、保险箱、统计与灵敏度设置保存在浏览器 `localStorage` 中，刷新不丢失。

### 建模管线

角色、武器、装备与场景道具均由 Blender 脚本程序化生成，无需外部商业资产：

```bash
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b -P tools/blender/build_characters.py
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b -P tools/blender/build_weapons.py
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b -P tools/blender/build_gear.py
"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b -P tools/blender/build_props.py
```

生成结果写入 `assets/models/`，灰度预览写入 `shots/blender/`。骨架、动画命名、枪口/铰链节点与 manifest 配置详见 [tools/blender/README.md](tools/blender/README.md)。

## 设计说明与已知限制

这是一个**单机硬核原型**，聚焦于"搜 → 打 → 撤"的核心体验：

- 没有联机、没有匹配、没有交易行；AI 敌人替代真人对手。
- 没有跳跃与攀爬；地图为标准平面地形 + 轴对齐碰撞体。
- 没有武器改装、钥匙与上锁房间、任务系统、等级/技能树。
- 默认美术与动画为程序化低多边形风格；已提供 GLB / PBR 资产管线，接入商业级资产后画质上限取决于外部资源。当前仓库未附带商业模型/贴图，因此默认观感仍不能等同于《暗区突围》的成品资产。
- 音效为 WebAudio 实时合成，风格偏"程序化"而非拟真录音。
- 地图为固定布局 + 随机刷点、随机容器类型与随机战利品。
- 浏览器刷新会在非战局界面之外中断当前战局（刷新后恢复战前存档）。

后续可扩展方向：多张地图的随机模块拼接、武器配件、保险箱内可放入钥匙链、商人好感度与限购、更丰富的医疗（骨折 / 手术包）、雨雪与昼夜、真正的 PvPvE。

## 技术要点

- **无资源依赖**：地形贴图、枪械模型、敌人模型、UI 图标全部由代码生成。
- **网格背包 / 弹挂**：物品具有真实占格（如步枪 4×2、护甲 2×2），支持堆叠、跨容器拖拽、双击快速拾取；基地与战局共用同一套物品模型。
- **程序化枪械**：按枪族生成独立的低多边形第一人称模型，包含导轨、瞄具、瞄准镜、弹匣、枪机、握把、分段枪托、护手与双手；无需外部模型文件。
- **地形 / 植被 / 天空**：高度场地形 + 坡度碰撞 + 自然山体边界；实例化 3D 草丛带风摆；树木由树干、枝干与叶簇卡片实时构成；天空为程序化穹顶贴图。
- **关节敌人**：层级骨架（髋、躯干、头、四肢关节）驱动的行走、待机、瞄准、后坐与倒地动画；迷彩布料、防具织物、头盔与背包均由代码生成。
- **资源点系统**：高/中/低价值区域控制容器类型、额外稀有掉落与守卫分配；野外只保留少量散落物资。
- **A\* 寻路**：地图生成后构建 1.5m 网格，敌人基于网格寻路并做卡死检测与重寻路。
- **程序化音效**：噪声 + 振荡器合成的枪声、脚步、命中反馈，环境风声持续循环。
- **本地存档**：战局结算时序列化整个仓库/装备/保险箱到 `localStorage`，支持重置。
- **无构建步骤**：原生 ES Modules + import map，Three.js 本地化，改代码刷新即生效。
